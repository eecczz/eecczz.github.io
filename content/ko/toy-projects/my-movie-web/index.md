My Movie Web은 TMDb API를 활용해 영화 정보를 검색하고 위시리스트를 관리할 수 있는 React 웹 애플리케이션입니다. 인기 영화, 검색 결과, 필터링, 정렬 기능을 통해 사용자가 영화 데이터를 탐색할 수 있도록 구성했습니다.

React Router 기반 라우팅, 컴포넌트 분리, 알림 메시지, 반응형 CSS를 다루며 프론트엔드 프로젝트의 기본기를 쌓은 작업입니다. 외부 API를 연결하고 사용자 상태를 화면 흐름에 반영하는 데 집중했습니다.

- 기술 스택: React, React Router, React Icons, React Toastify, CSS, TMDb API
- 구현 포인트: 영화 검색, 위시리스트, 필터링/정렬, 반응형 UI
- 저장소: [eecczz/my-movie-web](https://github.com/eecczz/my-movie-web)

## 주요 구현 포인트

### 영화 탐색 UI

![영화 탐색 UI](featured.png)

인기 영화와 고평점 영화 목록을 포스터 중심으로 탐색할 수 있게 구성했습니다.

### 검색과 필터링

![검색과 필터링](https://images.unsplash.com/photo-1489599849927-2ee91cede3ba?auto=format&fit=crop&w=720&q=80)

TMDb API 결과를 검색, 정렬, 필터링하며 원하는 영화를 찾는 흐름을 만들었습니다.

### 위시리스트

![위시리스트](https://commons.wikimedia.org/wiki/Special:FilePath/Search_Engine_Results_Page_%28SERP%29_Graphic_Illustration.png?width=960)

사용자가 관심 영화를 저장하고 다시 확인할 수 있는 클라이언트 상태 흐름을 구현했습니다.
